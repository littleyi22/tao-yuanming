# 陶淵明知識密室 2.0 🗝️

這是一個為國中生設計的**國文知識密室逃脫遊戲**，結合了陶淵明《五柳先生傳》的課文內容與生動的網頁解謎機制。

## 🌟 遊戲特色
- **沉浸式氛圍**：星空背景、懸疑背景音樂與專屬頒獎音效。
- **雙版本陶淵明畫像**：右側有活潑的 Q 版陶淵明搖擺陪伴，左側則有充滿古典氣勢的水墨風畫像。
- **互動解謎**：透過回答與課文相關的問題，收集 5 把魔法鑰匙。
- **成就證書**：通關後可以輸入姓名，領取專屬的通關證明！

## 🛠️ 開發與技術
- 原生 HTML / CSS / JavaScript
- RWD 響應式網頁設計
